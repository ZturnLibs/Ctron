# Ctron 规范格式(fmt-spec)

`ctron fmt` 的唯一权威格式。实现:token 流重排(`compiler-rust/src/fmt.rs`),不动 AST。
验收三断言(对全语料,`compiler-rust/tests/fmt_suite.rs`):

1. **幂等**:`fmt(fmt(x)) == fmt(x)`;
2. **AST 等价**:`parse(fmt(x)) == parse(x)`;
3. **行为矩阵不变**:行为文件 fmt 前后 `run_test_file` 结果逐项一致。

## R1 布局权威 = 原始源码间隙

§1.6 过滤器会滤除 `{`/`,` 之后的换行,过滤流丢失多行信息;fmt 的换行决策全部取自
**原始源码间隙的自由换行数**(扣除注释占据的换行):

- free ≥ 1 → 换行;
- free ≥ 2 → 换行 + 空行(**空行折叠为至多 1 行**,`fn a() {}\n\n\n\nfn b() {}` → 中间 1 空行);
- free = 0 → 同行延续(原始写在同一行的表达式不拆)。

## R2 缩进与块

- 缩进单位 4 空格,不用 Tab;
- 块的多行性:匹配大括号之间的原始间隙含换行 → 拆行布局(`{` 后换行、缩进 +1、`}` 前换行、缩进 −1);
  否则**内联块不拆**(单行 if 表达式:`let label = if n > 0 { "pos" } else { "neg" }`);
- 空块恒 `{}`。

## R3 `} else` 恒同行

`}` 与 `else` 之间无论源码是否换行,规范格式恒为 `} else {`(该归一化改变 token 流的换行
分布,但解析与行为等价——parser 对 `}` 后 `else` 前的换行按延续处理,§1.6)。`else if` 链同理。

## R4 链断行(首点链)

方法链中某 `.` 前的原始间隙含换行 → 该处换行 + 相对缩进 1 级:

    return xs
        .map(g)
        .filter(h)
        .len()

该补插换行在重词法化时被 §1.6 滤除(下一行以 `.` 开头 → 换行无效),故流不变、天然幂等。

## R5 空格表

- **两侧空格**:二元运算符(`+ - * / % == != < > <= >= && or .. 之外`/`=%` 回绕族)、
  `=` 及复合赋值、`->`、`=>`;
- **前紧贴**:` , : ) ] . ?`(及空块 `}`);索引/类型下标 `[`(`xs[i]`、`I32[N]`);
  调用 `(`(`f(x)`,可调用收尾后);一元 `!` `&`;range `.. ..=` 两侧;
- **后紧贴**:` ( [ . # @ ?`;一元 `- +`(按前一记号是否操作数收尾判定:`let x = -1` 一元,
  `a - b` 二元);闭包开启 `|` 与参数(`|x, y| body`,参数区紧贴、闭包体前有空格);
- **前紧贴后空格**:`:`(`x: I32`)、`,`;`#[pure]`、`@derive(Show, Eq)` 紧贴;
- **恒有空格**:`{` 前(`if cond {`、`Point { x: 1 }`)、`else`/`}` 后。

## R6 注释逐字保留

词法器吞注释;fmt 从 token span 间隙回收 `//`/`///`/`//@`,按前置换行分类:

- 独占行注释:当前缩进整行(跨行注释按原始行序,空行折叠适用 R1);
- 行尾注释:前置单空格挂在当前行;
- 注释文本逐字保留——**`//@ panic:` 等标记是 campaign/测试语义,fmt 不得改动**。

## R7 字面量保真

Str/Int/Float 一律按 span 从源码切片输出:插值 `"hi {name} x{n}"`、转义、进制 `0xFF`、
后缀 `255u8`、浮点 `2.5` 全部零改写(不做解码-再编码)。

## R8 其他

- 顶层声明之间空行:保留原有(有则 1 行,无则不加);
- 文件以单个换行结束,无前导空行;
- 括号组内保留原始换行结构(v0 不强制折行也不强制合并);**行宽 v0 不设上限**;
- 词法诊断非空 → fmt 报错退出(只服务合法语法面),不静默输出。

## CLI

    ctron fmt <file|pkg目录> [-w] [--check]

- 默认:格式化结果打印到 stdout;
- `-w`:原位写回(pkg 目录处理 `src/*.ct`,无 `src` 则目录直下,文件名序);
- `--check`:列出待格式化文件(stdout)后非零退出,不改写文件。
