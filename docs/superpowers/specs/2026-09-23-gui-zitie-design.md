# gui_zitie 中文字帖示例设计(2026-09-23)

**目标**:验证中文显示的专属 GUI 示例——大号字形方格字帖,对 M3 合流后的
FreeType 文本管线(实测测量 + 字符串纹理缓存)做观感与正确性双重验证。

## 版式(全部走现成样式面 size/w/h/align/bg/fg/gap)

- 深色应用底 + 宣纸色方格(96×96,`size:72` 单字居中);格间隙 2px 露底色 = 格线
- 标题行混排(ASCII+CJK,如「Ctron 字帖 · 千字文 第 1 页」)——全部走 bind 槽
  ({title}/{page}),叶字面量只留零标点静态词(按钮「换页」),规避内嵌重建插空格坑
- 结构:vbox > hbox(行)× 4 > each > label.cell;域包嵌套限深 16,each 允许在
  hbox 内(实现首步用最小探针证实,失败则退「each 体=行串」形态)

## 内容源(真实 IO)

- `zitie.txt` 存在则读入(用户可换字帖),否则内置千字文首段;去空白后按 UTF-8
  切单字(List[Str]),每页 20 字(4 行 × 5 字),行表 row0..row3 静态四列表驱动
- 「换页」按钮翻页(refill 四行;越界回首页);页码 bind 回显

## 验证口径(headless 断言)

1. 逐字 TEXT 命令字节断言:当页 20 字各自 d_expect_text(单字串)
2. 测量桥:`gui_ft_measure("天", 72)` 等大字号实测 > 0(extern 直连域库)
3. 命令数精确:title/page/20 字/按钮标签 = d_cmd_count 精确值
4. 翻页:第 2 页新字出现 + 首页字消失(d_expect_absent);页码更新

## 实施修订(2026-09-24,以落地形态为准)

- 版式 = 深底白字竖排笺(宣纸格底不可达,见下);cell 显式 `h:116` 撑开字距
  (label 高度来自 measure 行高,不写 h 时列内字形相互重叠)
- 内容 = 千字文全文 1000 字(50 整页;2026-09-24 用户裁决补全,原首段 32 字版
  的「末页不满列」边界覆盖随之退场,断言改翻页链第 2/3 页 + Esc 回首页;
  6 个重复字 发云昆巨戚洁 = 简繁合并产物,原文本各自不重)

## 差集与登记(域包泳道项,本例绕行不代修)

- **vbox/hbox 内嵌 each(容器套 each)段错误**——纸格底色路径不可达,格线以列距示意
- **each 挂 class 段错误**——列容器 gap/bg 无法经样式注入
- **rt_expect_text/absent 失败路径 dump 读 cmd0 的 union 文本视图**——cmd0 为
  RECT(按钮)时断言失败即段错误,掩盖真实失败信息
- 米字格斜线不可绘(仅矩形命令);字号静态样式值;无注音/笔画/描红
