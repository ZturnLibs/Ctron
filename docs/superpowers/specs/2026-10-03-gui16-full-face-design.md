> 「容器宽恒 GROW」存量口径站岗)。本案为 C 档 GUI-16 余留的完整面设计,

## 1. 问题

容器(vbox/hbox)的宽度消费被钉死为 GROW(撑满父宽)——`w` 样式对容器
不生效(zitie 同款事实,s37 验收口径)。值驱动布局(progress 连续条、
fill 面、环形、可折叠面板)需要容器宽随模型逐帧变化。

## 2. 设计

### 2.1 语义:引号串载体独占容器宽

- `w: "{expr}"`(**引号串形态**)对容器生效=FIXED 宽逐帧求值,与元素面
  同载体同求值器(gt_dim_v,§2.7 注入口径);
- 裸词 `w: 120` 对容器**继续不生效**(存量口径不破,零迁移);
- 语义分层:裸词=字面量(容器忽略,存量站岗),引号串=显式值驱动意图
  (容器遵从)。零歧义零迁移成本,s37 夹具原样站岗。

### 2.2 折叠缓存契约

- 现状:样式块按 class 折叠缓存,值驱动表达式藏于引号串,**缓存键=原文,
  求值=每帧**(gt_dim_v 已绕缓存,元素面实证);
- 完整面契约:**缓存存原文,消费侧逐帧解**——折叠期不展开表达式(零失效
  追踪),每帧 gt_dim_v 重放(即时模式小表达式成本可忽略,GUI-21 虚拟化
  同判);若未来 profile 需缓存求值结果,键=(class, 表达式原文, 帧号),
  登记远期不做。

### 2.3 发射面

- 容器分支(4240-4270 区)现走 gui_cfg/gui_cfg2/gui_cfg3 的 GROW 钉死;
  完整面=cls 抽 `w` 值,`gt_dim_v` 命中(引号串)→ sizing width FIXED
  (hmm 值同款),否则维持现路径;
- 覆盖:scroll 容器/overlay/浮层不受理(滚动宽=父宽语义不变)。

## 3. 验收

- 夹具:容器 w:"{n}" 随按钮逐帧变化(d_cmd_w100 断言),裸词容器宽不生效
  (s37 口径回归锁),嵌套容器值联动;
- 阶梯全绿(s37 站岗)+ progress 组件升级连续条(v1 分段折衷退役)。

## 4. 工作量

半天级:容器分支一路由 + gt_dim_v 复用 + 夹具一件。风险=Clay sizing
 FIXED 与 GROW 子混排的布局交互(≤1 夹具试金石先行)。

## 5. 裁决点(2026-10-03 用户裁决,已按裁决实施)

1. **统一语义(修订 2.1)**:引号串与裸词对容器同权生效,w 不写才忽略
   ——非原案的「引号串独占」;s37 free 迁移(摘惰性 w)、slider 轨道
   w:220 转 REAL(拖拽数学随调)、gallery card 摘惰性 w;
2. scroll/overlay 不受理 ✓ 照案;
3. progress 升级连续条 ✓ 照案(v2:track 200 + fill w:"{m.pw}",pbar
   块字符条退役;陈列室验收改几何断言)。
