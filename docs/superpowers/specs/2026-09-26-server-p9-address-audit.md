# P9 切片 1·emit 取址面审计报告(纯调研,零改动)

> 审计对象:coro_hybrid 发射产物(34.6KB,共享 bin)+ net/chan shim 源。
> 结论:**栈指针跨停车点存活实证两处**;方案推荐由 B 修订为 **A(分段+钉住)**。

## 证据

1. **视图跨停车**:`int64_t t_buf[4096]`(协程栈局部)以视图
   `{ t_buf, 4096 }` 传入 t_net_read_t;net_read_t 内 fdwait 停车期间,
   其 C 帧持有的视图 d 指针指向**同栈上层的调用方帧**——栈整体搬移(B)
   需帧内指针改写;A(分段钉住)内部指针恒有效。
2. **Drop 注册表驻留栈地址**:`ctron_drop_push(dth, &t_st)/(&t_srv)/(&t_ud)`
   ——scope 变量的**栈地址被全局注册表驻留**(变量生命周期内)。
   B 方案下旧栈释放 → Drop 派发踩陈旧地址;需注册表根扫描+区间改写
   (可做,再加一层机器)。A 方案:旧段钉住即恒有效,零改写。
3. **无逃逸面确认**:chan 槽 = ct_i 值拷贝(Str = 堆 char*,非栈);
   rt fdwait = key;Box = 堆——三者均无栈指针逃逸 ✓。

## 方案推荐修订(呈裁决)

| 方案 | 取址面审计结论 |
|---|---|
| **A 分段+钉住(修订推荐)** | 零栈图/零改写即安全(段钉住,协程存活期不回收);代价 = 段链开销 + 深递归链长 |
| B 拷贝 | 需 ①emit 栈帧布局表(编译器大改) ②drop 注册表等全局根的区间扫描改写——两件机器 |
| C 池化 | 保底不变 |

**推荐 A**:证据支持的最低风险路径;B 的栈图/根扫描作为 A 之上的可选演进
(B 的编译器机器与 A 不冲突,分段→拷贝可在线演进,go 1.2→1.3 同款路径)。

## ═══ T34 正案判决(2026-10-02,增长机制终局)═══

> 载体:T34 卡面(spec-gap 执行计划)坑位条款预授权——「若指针修复判决不可行,
> 大栈+触顶 panic 也满足规范字面并登记」。本节 = 该判决的正式成文;两案(A/B)
> 均被发射器挡死,证据链如下。

**判决:可增长连续栈(拷贝式)不可行;「1MB 大栈 + guard + 触顶诊断」
(a77f141f,T34 最小符合径)= §7.1 字面终形。** §7.1 承诺的是「上限默认 1MB
(可配),触顶 = 任务边界 panic」——未承诺起步尺寸,现形全量兑现;§7.10
过渡口径注记相应收窄为仅调度面(本次 work-stealing 落地后调度面亦合)。

**B(拷贝式)阻塞证据 = 三件机器**(原审计两件 + 本判决新增第三件):

1. emit 栈帧布局表(原审计①):栈上局部引用/帧链的精确位置需发射器输出
   布局表;C 发射后宿主 cc 自由布局(spill/重排),发射器单方面不可知。
2. 全局根区间改写(原审计②):drop 注册表驻留栈地址(本审计证据 2),
   拷贝后须全域根扫描改写。
3. **callee-saved 寄存器镜像修复(新增)**:rt_swap 保存/恢复 x19–x28
   (arm64)/rbx,r12–r15(x86_64),宿主编译器可自由在其中缓存栈对象地址;
   无栈图不知哪个槽位是栈指针,修复=猜。保守区间改写(凡落在旧栈区间的
   字一律加 delta)对「地址值整数」语言不健全——FFI 面(Int 持地址是合法
   值)即假阳性改写。三件机器同一处生根:精确栈图不可得 ⇒ B 整体不可行。

**A(分段+钉住)同判阻塞(修订原审计的推荐)**:原审计「A 零改写即安全」
只覆盖指针有效性(段钉住),未覆盖 **guard 触发后的续跑机制**——分段栈
的段链接发生在函数序言(Go 1.2 morestack:发射器在序言插栈限检查),而
本实现无序言检查,栈尽 = guard 页 SIGSEGV 深在宿主编译帧内;信号处理器
内续跑只有「搬动出错帧」一条路,而 arm64 尾声 `ldp x29,x30,[sp],#imm`
以 sp 相对量回卷——叶帧搬到新段后,返回落点 sp 在新段 ≠ 调用方帧(旧段)
⇒ 调用方经 sp 相对寻址的局部全踩陈旧。即:**无发射器序言检查机器,A 与
B 挡在同一堵墙**(序言检查/栈图同族的编译器机器)。

**解锁条件(单列,不随 T34 销账)**:发射器 morestack 序言检查(与 B 的
栈图同族编译器机器)。触发条件:C100K+ 实测栈内存成为瓶颈,或应用契约
(lane 预算化)无法再压。在此之前,深栈需求由 1MB VA 上限 + OS 惰性提交
承接(设计底稿 0926 终实测:RSS 反优于 64KB 强触形)。

**调度面(work-stealing)不受本判决影响**:同一 T34 卡内,调度器升级于
2026-10-02 落码(每 worker 环形双端队+邻位轮转偷取,种子模式全量旁路;
见 ctron_rt.c 头注 T34 节)。
