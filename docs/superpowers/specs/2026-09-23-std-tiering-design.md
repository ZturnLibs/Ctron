## 0. 本文回答什么

std 目录目前 gui 与 net/http/tls/db 混居。上轮已实证:**加载是 use 闭包驱动的
(parse_pkg.ct pkg_load_use_done),目录混居零编译成本**——裸程序产物 0 个
net/gui 符号;+use std.net 产物 +216 行 C/0.37s;+use std.gui +2056 行/2.4s。
真正的债是**口径混居**:README 模块清单只认纯核心 19 模块(域包不在册)、
宪章"模块互不 use"已被域包打破、09-21 spec §8.3.2"目录内零 use"提案当日即被
http 域全套突破。

本文交付:①三档分层模型与现有包归层(§2);②后续包准入判断标准(§3 判定表);
③按场景的处理流程(§4);④拆分触发条件(§5);⑤宪章 v2 修订清单(§6)。

**非目标**:不动目录、不迁包、不改加载器、不裁决 json_write 合并(09-21 §8.3.1
维持悬置)——本稿是纯口径收编,落地动作只有 README 修订一节。

## 1. 事实底盘(2026-09-23 实测)

### 1.1 依赖面三档实况

| 档 | 实测依赖 | 成员 |
|---|---|---|
| T1 纯 Ctron | 零 C 源;编译器内建(read_file/fs_*/now_ms)视同无依赖 | README 清单 19 模块 + 后补 uuid/config |
| T2 系统面 | libc/socket + 包内 c_src 或 vendored **纯用户态** C | net(bind/rt 协程运行时)、http(+vendor/deflate)、tls(+vendor/tls/mbedtls)、db(pg/redis 线协议 in-repo C,含 winsock 分支) |
| T3 平台面 | 拖**平台服务**(窗口系统/GPU/显示) | gui(clay+raylib vendored,raylib 拖 X11/GL;headless 须命令缓冲 shim) |

### 1.2 use 既成事实(宪章 v1 已破,须转正而非假装)

- **域内 use**:http/client.ct → std.http.parse/message;db/pool.ct、rowmap.ct → std.db.pg。
- **跨域下行 use**(T2→T1):db/pg.ct → std.crypto(SCRAM);http/ws.ct → std.crypto;
  http/client.ct → std.net.bind。
- 无一例上行 use(T1 消费 T2/T3),无一例环——好纪律已经存在,只是没成文。

## 2. 三档分层模型

**判定线画在"平台服务依赖"**,不画在"有无大型 C 库":tls 挂 mbedtls 但纯用户态、
headless 可绿,划出服务器档违背战略;gui 拖窗口系统,才是不依赖显示就不存在的包。
可操作试金石:**headless 环境能否构建+跑绿验收**。

| | T1 核心 | T2 系统面 | T3 平台面 |
|---|---|---|---|
| 定义 | 纯 Ctron,零 C 源 | libc/socket + 自带/vendored 纯用户态 C | 依赖窗口/GPU 等平台服务 |
| 成员 | 清单 19 + uuid/config | net http tls db | gui |
| use 权 | 不 use 任何域包 | use T1;域内 use;跨域须登记 | use T1(T2 须登记) |
| 门禁 | stdpkg 全量消费+parity 矩阵+种子逐字节同步 | 域包自带消费测试,headless 绿为准入条件 | 永不进 std 通用门禁,泳道自有验收 |
| vendored C | 禁止 | vendor/<域>/,包内 c_src 只放自写胶水 | 同左(现况已合规) |

## 3. 准入判断标准(判定表)

新包 P 申请入 std,依次四问,**全过才准入**;任何一问不过 → 09-21 §3.3 候补层
登记,或按注册表包形态外置:

- **Q1 依赖面**:P 的依赖 ≤ 所申报档上限?零 C 源→T1;纯用户态 C→T2;平台服务→T3
  (T3 默认劝退:T3 在 std 只应是历史例外,新 T3 直接走注册表包形态,见 §4)。
- **Q2 消费面**:有无真实需求源(泳道/examples/规范承诺)?沿用 09-21 §2.4
  "消费面即需求源"——"Go 有所以要有"不成立。
- **Q3 三宿主税**:T1 新面三线(ctron test/自举解释/发射 C)可验?T2 的 C 面
  逐宿主行为一致或显式登记受限口径(net.ct 头注先例)?付不起→候补层。
- **Q4 泳道所有权**:P 归哪个泳道所有(db=服务器线 P5 先例)?无主包不入,
  维护权悬空即债。

**档次流用规则**(全部为既成事实成文化):
1. use 只许下行(T3→T2→T1),上行一律不许;
2. T1 互不 use(宪章 v1 #2 对核心面原样保留);
3. 域目录内 use 允许、禁环(替代 09-21 §8.3.2"目录内零 use"——该提案当日即被
   http 域全套突破,改按现实转正;菱形规避依加载器 ⑥ 口径);
4. 跨域 use 允许但须包头注登记消费闭集(http/client、db/pg 已示范此写法);
5. T1 禁止拖 C:缺功能开 T2 新包,不许给 T1 加 C 源(守 vendored 闭集)。

## 5. 拆分触发条件(何时把包请出 std)

1. **CTCL 包管理器/注册表落地**(README 已承诺 std 为上游注册表形态)→ T3 全部
   迁出,gui 第一个;
