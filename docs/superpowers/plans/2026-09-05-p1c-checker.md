**关键机制设计**:
1. **Ty**:经典一等表示(Vars + 一致化);签名必标注(规范保证)→ 泛型按调用点一致化实例化;字面量自适应用 expected-hint 双向传递。
2. **prelude 注册表**:硬编码语料所需 API(Option/Result/List/Mutex/Channel/Task/Atomic/Global/Arena/ArenaList/Simd/AnyError/Parallel/Str/String 方法 + assert 族);std.fs.Fs/std.time.Clock 等 Cap trait;stdweb.dom(std.title/set_title)。
3. **Send**(§7.4 表):值类型递归字段;class = 全 let 字段且递归 Send;`T[]` 恒非 Send;`&T[]` 看元素;`&Trait` 恒非 Send;Mutex/Atomic/Global 恒 Send。强制点:spawn 闭包捕获(E3010,语法级捕获分析)、Channel 元素类型(E3020)、static 存储(E3031)。
4. **分配效果**:函数级定点求解;deny = to_string/插值/集合构造与 push/Box/类构造;allow = arena.*/into_gc;dyn 调用保守 alloc,除非 trait 方法带 #[no_alloc] 契约(违约在 impl 处 E3040)。强制点:own 块(E3040/E3060)、#[no_alloc] 体、bare 档全部、bare static let。
5. **穷尽性**:仅 enum;wildcard/绑定臂全覆盖。
6. **comptime**:静态 Cap 调用检查(E6020)+ 常量初始化器的步预算解释器(自递归不终止 → E6010;fib(10) 正常)。
7. **caps**:多文件包读 Ctron.toml [caps];&Cap-trait 参数 → 要求 key(如 Fs→fs);缺失 E4010。
8. **档位**:single-file 由测试名决定(08_bare→bare、10_web_dom→web);web 档 stdweb.dom 可用;bare 档全量 no_alloc 语境。

**验收**:`cargo test` 全绿(既有 50 + check_suite);`meta_check` 绿。
