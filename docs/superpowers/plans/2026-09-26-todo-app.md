# todo_app 实施计划

> **For agentic workers:** 本计划由当值会话内联执行（superpowers:executing-plans 路线）；
> 步骤用 checkbox 跟踪。Ctron 语言坑位清单见「Global Constraints」，写码前必读。

**Goal:** `examples/todo_app` —— 浏览器可用的多用户 todo 管理应用（真密码登录 + Cookie
会话 + 文件持久化 + 服务端渲染 HTML）。

**Architecture:** 多文件包（`use todo_app.store/views`），瘦 main（HTTP 循环+路由）规避
主文件 20480B emit 上限；存储与视图为纯依赖模块。串行一连接一请求沿 todo_api 骨架。

**Tech Stack:** Ctron（自举发射 C），net + http.parse + http/frm{auth,html,metrics,body,openapi}
+ http/form + std/{crypto,rand,strconv,time,fs}。

## Global Constraints（血泪清单，违反即红）

- 无位运算算符：`&`(借用)/`|`(死旋)/`^`(E1001) 一律不可用于位运算——位操作用 std/crypto 已有面或算术等价。
- 无三元表达式：用 if 表达式（J20 宪法终形态）。
- 语句禁 `;`；字符串字面量裸 `{` 须写 `\{`；or2 调用全括号。
- lane 字面量槽数 interp/emit 不对称：禁巨型 `[0,0,...]` 字面量（todo_api 的 `I64[4096] = [0,0,0,0]` 少槽写法是先例——少槽初始化合法）。
- 跨包引用即请求：use 必须显式列出每一符号。
- run.sh/构建须 `export CTRON_STDPATH="$ROOT/std"`；发射臂构建 `compiler/native.sh` 先行。
- 验证一律 seed 口径：`ctc`（勿用旧 bin）；`ctc test` 解释口径跑 test 块。
- 主文件 src/main.ct 发射产物 <20480B（HTML 拼装全在 views.ct）。
- 用户可见文本一律 `ht_esc`；uid 注册域 `[A-Za-z0-9_-]{1,32}`（与 auth au_uid_ok 同族收紧）。
- fmt 收口：`ctc fmt --check` 净；提交 pathspec 限定（仓库有他泳道未跟踪文件）。
