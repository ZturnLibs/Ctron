# Repeat 字面量(`[v] ** N`)执行计划

> 2026-10-09 立稿。来源=1009 字面量初始化/插值设计讨论第二轮;
> **用户裁决:repeat 字面量落地,形态 `let table: U32[256] = [0] ** 256`(Zig 式后缀)**。
> 用户圈选前置项「comptime fn 返回定长数组的发射臂需先验证」——已验证完毕,
> 结论=解释臂全绿、发射臂双红(§2 实锤),红账入 W4。

## 0. 裁决记录(规范性)

1. **做,语言面**(能力优先于 hack,0924 横切裁决):字面量表达力缺口走语言扩展,不走库函数兜底。
2. **拼写 = `[v] ** N` 后缀 repeat**;块重复自然推广:`[1, 2] ** 3` → `T[6]` = `[1,2,1,2,1,2]`。
3. **N 须编译期可求值**(v1 = 整数字面量 + `const` 名;运行时表达式 → 诊断报错)。字面量 = 编译期形状的纯度不动摇;运行时长度需求显式走库函数(切片面 `zeros` 族已有;`List.filled(n, v)` 非阻塞可随批,R5)。
4. **短字面量裂缝随批修**(R4):`var buf: I32[8] = [1, 2]` 现状双路放行(chk OK)+ 发射靠 C 部分初始化零填充 + 长度元数据跟字面量(=2,后续 `buf[2]` 报 `index target`)——修复为按 spec §3.6 报 E2010 系(`T[2]`→`T[8]` 无隐式转换),neg 钉子双口径。
5. **本批不做**:List/Set 期望类型适配、Map 字面量、字段默认值、多行串、原始串、`{f:.2}`(上轮 8 裁决点另行待裁);但设计不堵 List 适配路(repeat 展开结果可复用为适配源)。

## 1. 背景与证据(1009 探针考据)

- **ctecho 活标本**:`examples/ctecho/src/main.ct:19` `var buf: U8[512] = [0, 0, 0, 0]`——512 缓冲写 4 个零,靠 UB 活着,repeat 需求真实性的最好论据。
- **短字面量 UB 三连**(探针 `I32[8] = [1, 2]` 实证):① `ctron-cc run` 放行 + `ctron-chk check OK`(无长度门);② 发射产物 `int32_t t_buf[8] = {1, 2}` 靠 C 零填充;③ 元数据错位——后续 `buf[2]` 报 `index target`,`sum(buf)`(形参 `I32[8]`)又按 8 元素 memcpy。同份代码双口径行为劈叉。
- **设施盘点**:切片面 `arena.zeros[T](n)`/`r.zeros[T](n)`/`Static.zeros[T](n)`(.bss)已有(仅零值);`str.repeat`、`Simd.splat` 已有;**定长数组 `T[N]` 与 `List[T]` 全缺**。
- **`**` 现状**:`[0] ** 4` → `E2020: 未解析的名称: *`(无静默误解析)——新 token 可安全认领,存量程序零破坏。
- **词法考据**(compiler/src/lex.ct):标点=原始串形态(ops 表);`**` 需最大 munch 分支(先于 `*` 匹配);须加入 `nl_set_line_end` 行尾延续集(repeat 尾置换行合法)。
- **解析考据**(compiler/src/parse_expr.ct):二元节点 = `Binary` [op, l, r] + `nstamp` 行号戳(v0.7 修订一,E2010 检查依赖末位行号)。repeat **立专节点 `Repeat` [elem, count] + nstamp**,不复用 `Binary`——类型规则特异(count 编译期、结果维度相乘),复用会污染 Mul 语义通道。

## 2. 前置验证结论(用户圈选项,1009 已完成)

| 探针 | 解释臂(`ctron-cc run`) | 发射臂(`ctc.sh emit` + cc) |
|---|---|---|
| `comptime fn build() -> I32[4]`{循环填表,返回} + `const TAB: I32[4] = build()` | **绿**(`t1=1 t3=9`) | **红**:产物缺 `t_TAB` 声明,cc 报 `use of undeclared identifier 't_TAB'` |
| `const ORIGIN: I32[3] = [0, 0, 0]`(纯字面量) | **绿**(`o1=0`) | **红**:发射管线内部 `E1001: 未闭合的块`,且**错误文本泄漏进产物 .c 首行**(发射失败不得产出伪 .c——随 W4 一并治) |
| 对照:非 const 局部数组(probe_a) | 绿 | 绿(`t_buf` 正常落声明) |

结论:**const 位聚合(字面量与 comptime fn 两路)发射面全红**——`const CRC_TAB` 计算表全链卡在此处,是本批发射侧的主工程量;repeat 本体(局部绑定位)反而是小件。

## 3. 设计

- **词法**:`**` 最大 munch 新分支(在 `*` 单字符分支之前);入 `nl_set_line_end`(不入 `nl_set_next`——repeat 左目在前缀位无意义)。
- **解析**:postfix 层(p_postfix/p_una 链)识别 `**`,右目限整数字面量或 const 名(v1);节点 `Repeat` [elem, count] + nstamp。非结合:`a ** b ** c` 直接 E1001(嵌套 repeat 无语义,层层左括号显式化)。
- **sem**:
  - elem 直接类型 `T[N0]`,count 编译期折叠 N → 结果 `T[N0 * N]`;期望 `T[M]` 上下文(标注/形参/const 类型)要求 `N0 * N == M`,不符 E2010 系(与裁决 4 同门报错形态)。
  - count 运行时表达式 → 新诊断码(取号按 spec §10 注册表实测登记,COVERAGE 同批);count 负数 → 同门报错;count = 0 合法(`T[0]` 空数组)。
  - elem 非数组(裸标量 `[0] ** N` 中 `[0]` 即 `T[1]`,天然合法);非数组类型 ** N → E2010。
- **解释臂(CVM)**:`Repeat` 求值 = elem 求值 + 块复制展开。
- **comptime 臂**:CVM 认 `Repeat`;**步数按块计 1 步,不按元素**——`[0] ** 4096` 若逐元素计步必爆 §8.4 的 1200 步预算(E6010),求值器须特判整体物化(风险节同款)。
- **发射臂**:
  - 局部绑定:全零特判 → `memset`(或栈 `.bss` 式零初始化);非零 → 首块展开 + `memcpy` 循环;`[v] ** N` N=1 退化为普通字面量。
  - const/static 位:静态初始化器展开进 `.rodata`/`.bss`(依赖 W4 双红修复)。
- **CTML/字符串面零交集**:`**` 不入字符串扫描与 `\{` 插值通道;发射产物 C 中 `**` 不出现(展开为循环/内建调用)。

## 4. 工作项分解

- **W1 词法+解析**:lex.ct `**` munch 分支 + 延续集;parse_expr postfix 臂 + `Repeat` 节点;neg 钉子(`**` 后缺 count、count 非整数、双重 `**`)。金样重冻结随批。
- **W2 sem+解释臂**:类型规则/期望类型折叠/诊断码;CVM 求值(块计步特判);夹具 pos 三件(标量 repeat/块重复/const 位字面量)+ neg 三件(N 运行时/长度不符/负数)双口径。
- **W3 发射臂(局部绑定)+ 短字面量裂缝**:repeat 展开/memset 特判;**同门修裁决 4**——数组字面量长度 ≠ 标注长度双口径报错(现 `ctron-chk` 也放行,chk 门一并补),neg 钉子 `I32[8]=[1,2]`;连带核 `index target` 元数据错位根因(绑定类型应以标注为准)。
- **W4 const/static 聚合发射双红**:① comptime fn 数组返回/const 位消费落声明(`t_TAB` 缺失);② const 数组字面量管线内 E1001;③ 发射失败产出伪 .c 的行为治理(失败即失败,错误文本不得进产物)。**`const CRC_TAB = build_table()` 计算表全链在此收口**。
- **W5 文档与改写**:spec §3.6(字面量直接类型补 repeat 形态)/§4(表达式节)+ COVERAGE 登记 + e8_corpus 负例;ctecho 缓冲改写 `U8[512] = [0] ** 512` + 3/3 冒烟 + 64KB 回环回归;示例/README 若有手写长零数组同步。
- **门(全批)**:smoke 全绿 + suite 双列全绿 + 新夹具双宿主逐字一致 + ctecho 冒烟 + 发射确定性(CTRON_GC=1 env 与 off 逐字一致,立规在案)+ decl 锁实测申报(新助手 fn 是否入锁,勿推算)。

## 5. 风险与在册坑位

- **comptime 步数预算**:`[0] ** 4096` 逐元素计步必爆 1200 步(E6010)——CVM 块物化特判是硬前置,不是优化项。
- **emit 管线不对称**:验收一律 `ctc.sh emit`;`ctron-cc emit`/`ctron-emit` 直发单文件会静默丢程序体(1009 探针再证,433 行纯 prelude)——本批不修,坑位延续在册,但 W4 伪产物治理后须复核该行为是否同根。
- **机刷守则**:worktree 留底、提交 pathspec 限定、夹具号执行前实测再占;对端可能并发改 trans_expr.ct(发射泳道热区)。
- **短字面量修复的波及面**:现网仅 ctecho 一处依赖短字面量 UB(W5 改写即消);lib/std 无此形态(1009 grep 证)。修复后须全量 smoke 确认无隐性依赖。
- **`\}` E1001 族**:W4 的 const 聚合红与字面量发射臂同片(trans_expr),修复时先跑 e8_corpus 再动刀,防误伤插值扫描通道。

## 6. 验收清单

1. `let buf: U8[4096] = [0] ** 4096` 双宿主跑通,发射产物含 memset 特判。
2. `[1, 2] ** 3` 块重复 → 6 元素逐字一致;`[0] ** 0` → 空数组合法。
3. `const CRC_TAB` 计算表全链(comptime fn 循环填表 + const 消费)双宿主绿——前置验证双红销账。
4. neg:`I32[8] = [1, 2]` 报错(chk+run 双口径)、`[0] ** n`(n 运行时)报错、负 count 报错、`**` 误用三件。
5. ctecho 改写后 run.sh 3/3 + 64KB 回环 65536/65536。
6. smoke/suite 双列全绿;发射确定性 env 一致性通过。
