## 设计要点

- **Send 判定(§7.4)**:值类型递归;class = 全 `let` 字段且递归 Send;`T[]` 恒非 Send;`&T[]` 依元素;`&Trait` 恒非 Send;Mutex/Atomic/Global/Sender/Receiver/Task/String/Box 恒 Send;**只对可证明非 Send 报错**(未知/泛型参数保守 Send → 行为文件零误报)。
- **捕获分析**:spawn 闭包引用外层绑定集合(env 快照于调用点),对每个捕获做 Send。
- **类型推导(语法导向)**:注解 + 构造路径/`Mutex[T](…)`/`Channel[T](…)`/`Some/None/Ok/Err`,覆盖语料所需,不做全量双向推断。
- **错误恢复**:纯 AST 遍历,无歧义上下文才触发;所有检查对"无法解析"情形静默跳过(防误报)。
