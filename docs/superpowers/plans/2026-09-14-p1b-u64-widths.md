**Goal:** U64/USize/ISize 获得真 64 位语义——解释侧精确存储 + 检查算术(§4.5),
发射侧 `uint64_t` 存储槽 + 溢出检查帮手,as[U64]/as[USize] 发射落地;03b 既有断言不翻。

**Architecture:** 解释侧新增 **"7" 值域**(无符号 64 十进制文本,复用 6 域 c6 竖式算术
全家,界门换 `c6_in_u64` ≤ "18446744073709551615");ISize 并入既有 "6" 域(同宽同检查,
§3.1.1 同构)。发射侧仿 "6" 先例:`ct_ty_code` U64/USize→"7"、ISize→"6";`ct_ctype`

uint64_t + panic 消息镜像宿主);Binary/复合赋值路由;as[U64]/as[USize] 发射
TypeArgs-callee 拦截 → `(uint64_t)(x)`(§3.6 窄化=截断)。

**Tech Stack:** Ctron(eval_val/eval_run/eval_expr/eval_call/trans_ty/trans_expr/
trans_stmt/driver_emit)、03b 语料(suite 双通道)、fx_u64 新夹具、smoke/suite/固定点。

## Global Constraints

- **03b 不得翻**:`big.as[U32]() == 4294967295u32` 的巧合相等必须保持(as[U32] 走
  既有 I 域回绕路径,本片不改 u32 后缀/u32 目标行为);u8/i16 后缀与 W 域不动。
- spec §3.1:定宽 + **默认检查算术**(非回绕;宿主 ck_int 即 panic 口径)——溢出
  panic 消息镜像宿主 "integer overflow (±*)" / "division by zero"。
- 命中即停:u64/usize 后缀字面量的发射面 v0 不做(03b 无此形态);ISize 与 I64
  在无注解字面量自适应下同域。
- 自举传播安全:compiler/src 与 std/ 无 U64/ISize/USize 注解(侦察 0 命中),固定点
  产物不受影响;eval 基建不可用 dvi 承载 ≥2^63 值(沿用 c6 文本域)。
- 门禁:suite 63/63(03b 双通道)+ smoke --full(std 泳道 3 红除外)+ 固定点逐字节。
