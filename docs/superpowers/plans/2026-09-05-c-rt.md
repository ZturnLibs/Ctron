## C4-c:struct/class/Box/字符串 API/match 结构模式
允许表新增 `02e_match_patterns`/`03_values_refs`/`03c_str_string`(合计 32 test 块全过):
- `V_STRUCT`(struct 值 vs class 引用,含 `is_class`):字面量构造、字段读写、成员赋值
  (`b.x = 10`);赋值/绑定语义 = struct **值拷贝**(clone_val 深拷贝)、class/Box **引用共享**;
- `V_BOX`(Box[T](v) + 自动解引用:字段读/结构模式穿透);
- 枚举单位变体(Red/Green/Blue)、整型字面量模式(0/7/`_`)、`Pt { x, y }` 结构模式(简写绑定);
- `Str` `.char_len`(UTF-8 标量)/`.len`(字节)/`.to_string()`(String 持有,隐式降格 Str)。

## C4-b:GC 复合值 / Option / match / 闭包 / 函数值

- 数组/切片值:`V_ARR`(arena 元素块),定长数组字面量、索引、`.len` 属性、`for x in xs` 迭代、作 `I32[]` 参数透传;`Str.len` 字节长。
- 标签值 `V_TAG`(变体名 + 载荷表):`Some/None/Ok/Err` 与文件枚举变体(`Advance(n)`/`Stop`)构造与裸值;Option 方法内建 `map/or/expect`;`?` Try(空 → 提前 return);match + 模式绑定(`Some(v)`/`Advance(n)`/unit/通配/字面量)。
- 函数值:命名函数 `V_FN`(`map(twice)`)与闭包 `V_CLOSURE`(捕获环境指针,追加式环境不回收,指针即快照)。
- 插值 `{expr}` 经包装再解析于当前环境求值(支持成员链/索引/方法调用)。


## 已实现语义(值/执行域)

- **值**:I8..U64/ISize/USize(64 位宽)、F32/F64、Bool、Str(arena)、Void、range 值。
- **数值**:默认 I32 / 字面量后缀;绑定与参数按声明类型**自适应**(域外 panic);检查算术溢出 panic("overflow");`+%`/`-%` 回绕;除法/取模除零 panic("division by zero");`%` 符号随被除数;浮点字面量与运算。
- **表达式**:优先级、比较、`&&` 短路、一元、`if/else` 值、块尾值、range 值、插值字符串(`{expr}` 经包装再解析,于当前环境求值格式化)。
- **控制流**:while、`for i in 0..n` / `0..=n`(range 值可先绑再迭代)、跨块遮蔽。
- **函数**:顶层 fn/递归;UFCS(`21.double()` 解析为自由函数);`x.as[T]()` 显式转换(截断/回绕,`300.as[U8]()==44`、`3.5.as[I32]()==3`);断言内建 `assert/assert_eq/assert_ne`。
- **运行时**:setjmp/longjmp 单点中止;一文件一 arena;`suite_rt` 按允许表评分。
