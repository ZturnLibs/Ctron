# Ctron C 版:C4-a 解释器(执行层起步)实施计划

> **决策上下文**:见 `compiler_c/README.md`。执行层(行为/panic 语料运行)按语言域切分推进;C4-a 先覆盖**纯数值/逻辑/字符串/范围**域,GC/并发/own/trait 对象等域留待后续增量,允许表显式列明,杜绝“假绿”。

**Goal:** `src/rt.c` 解释器 + `suite_rt` 运行器:对允许表内 .ct 逐 test 块执行,panic 文件要求 panic 消息含 `//@ panic:` 子串;未支持文件计 deferred(不运行、不计失败)。

**C4-a 允许表(全部真实通过)**:`01_basics.ct`、`01_overflow.panic.ct`、`02d_divzero.panic.ct`、`03b_numeric_widths.ct`、`04b_logic.ct`(6+1+1+2+6 = 16 个 test 块全过)。

## 已实现语义(值/执行域)

- **值**:I8..U64/ISize/USize(64 位宽)、F32/F64、Bool、Str(arena)、Void、range 值。
- **数值**:默认 I32 / 字面量后缀;绑定与参数按声明类型**自适应**(域外 panic);检查算术溢出 panic("overflow");`+%`/`-%` 回绕;除法/取模除零 panic("division by zero");`%` 符号随被除数;浮点字面量与运算。
- **表达式**:优先级、比较、`&&` 短路、一元、`if/else` 值、块尾值、range 值、插值字符串(`{expr}` 经包装再解析,于当前环境求值格式化)。
- **控制流**:while、`for i in 0..n` / `0..=n`(range 值可先绑再迭代)、跨块遮蔽。
- **函数**:顶层 fn/递归;UFCS(`21.double()` 解析为自由函数);`x.as[T]()` 显式转换(截断/回绕,`300.as[U8]()==44`、`3.5.as[I32]()==3`);断言内建 `assert/assert_eq/assert_ne`。
- **运行时**:setjmp/longjmp 单点中止;一文件一 arena;`suite_rt` 按允许表评分。

## 诚实边界(未支持,deferred = 29)

GC 集合/类/Box、Option/Result/Error 链与 `?`、match/模式、闭包、结构体/切片/定长数组、own 块/arena、scope/spawn/Channel/Mutex/Atomic、trait 对象与方法分派、stdweb/ffi 等 → 后续 C4-b(GC/数据结构+match)、C4-c(并发运行时)、C4-d(其余)逐域并入允许表。
