**Goal:** 拼音组词期间,候选串以 marked range 内联显示在聚焦 input 框内(不丢、
不错位),候选窗跟随光标;组词状态经 bind 通道成为可观察/可测状态。

**Architecture:** ObjC 臂(gui/c_src/ime_shim.m,构建配方 `-x objective-c` 单
文件,Darwin only)在 gui_clay_init 时 runtime-swizzle `GLFWContentView` 三方法
(`setMarkedText:`/`insertText:`/`firstRectForCharacterRange:`),镜像组词串与
caret 矩形到 C 全局;域包 input 绘制分支读 `gui_ime_preedit()` 在光标处内联
渲染(下划线 RECT 标记 marked range),每帧 `gui_ime_set_caret()` 反喂光标
rect;headless 经 d_ime_set 注入组词态。Linux XIM 登记后续(远期)。

**Tech Stack:** ObjC runtime swizzle(objc/runtime.h)、raylib GetWindowHandle
(NSWindow*)、域包 gui.ct input 分支、s47 夹具。
