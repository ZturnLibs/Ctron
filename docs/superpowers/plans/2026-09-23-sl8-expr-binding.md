## 架构定音（本计划裁决）

1. **规范形 = 去空白原文**：`{...}` 槽内容在所有面（编译骨架/check/域包树/运行时
   查询名）统一存储为**去除全部空白后的表达式原文**（字符串字面量内空白保留）。
   该形对两侧词法粒度不变——W1 按 token 空格拼接与域包按字节原始捕获在剥空白后
   必然同形（如 `{a + b}`→`a+b`、`{user.name}`→`user.name`），s22 双端差分可证。
2. **执行架构分层**：8a 只动解析/检查/存储（运行时中性）；8b 域包求值器（受限
   纯读解释：字面量/标识符/点链/算术比较/len，环境 = 现有 bind 名通道 + 新值环境）；
   8c 编译器 on: 自动闭包（emit 面生成事件闭包，钩子/锚退役）。
   编译期自动闭包是 L2 正统（设计 §5.1），域包解释执行框架内 on: 先走
   "表达式→动作名+实参字面量"的受限形态，8c 收编。
3. **E8190 纯读门 = check 面静态走查**（赋值/复合赋值/自增减 token 形态即拒；
   on:/fn props 槽豁免）；可变方法调用的深度判定随 8c 类型面补强，8a 先拦
   token 可判定形态（语料可测确定性优先）。
4. **运行时兼容**：ident 与点链形槽继续按名查询（现协议零破坏）；含运算符的
   表达式槽在 8b 前由运行时响亮 panic（带原文），不静默空渲染。
