# Ctron P1-B:解析器实施计划

> **For agentic workers:** 本计划按"批量执行"模式运行——连续完成 Task 1–3 后统一跑测试修复,再执行 Task 4–5,最后统一审查。步骤仍用 checkbox 跟踪。

**Goal:** 实现规范 §1.7 EBNF 的完整递归下降解析器:除 `01c_parse.neg.ct`(E1001)与 `06_static_var.neg.ct`(E3030)外,61 个测试文件全部零解析诊断;`static var` 恢复产出 E3030;AST Debug 输出可作为跨实现差分(与 C 版)的产物形态。

**Architecture:** `src/ast.rs`(纯数据 AST)+ `src/parser.rs`(游标式递归下降,Token 流含 Newline 记号)。`parse_src(src)` = lex + parse,诊断合并。修复 P1-A 遗留的 lexer 错误恢复递归(M2 硬前置)。

**Tech Stack:** Rust,零依赖,仅 std。

## §0 规范裁决(随本计划生效,规范 v0.5 修订由协调方执行)

1. **§1.8 泛型/索引消歧补充**:`]` 后跟 `(` 或 `(`-类 → 类型实参;否则先按索引解析,**索引内容不是合法表达式时回退为类型实参**(覆盖 `Simd[F32, 4].splat(...)`——内容含顶层逗号,索引解析必然失败)。

### 关键算法(规范性,实现必须一致)

- **优先级**(§4.3,优先级攀爬):`or`(1) → `&&`(2) → 比较(3,**不可链**:一轮后仍是比较运算符 → E1001"比较运算符不可链",消费后继续,只报一次)→ range(4) → 加减/回绕(5) → 乘除模(6) → 一元(7) → 后缀(8)。二元前均先 `skip_newlines` 不需要——词法过滤已抑制跨行;同行内无换行记号。
- **结构体字面量开关**:解析 `if`/`while` 条件、`match` 待匹配表达式时传 `allow_struct=false`(关键字语境独占其后 `{`);其余表达式位置 `true`。
- **`[` 消歧(§1.8+裁决)**:后缀 `]` 后是 `(` 或 `{` → TypeArgs;否则保存游标尝试 Index(内容为单表达式),遇顶层 Comma 失败 → 回退游标解析 TypeArgs。
- **`else` 同行**:then 块 `}` 后,若紧跟 Newline 且其后是 `else` → E1001"`else` 必须与 `}` 同行";紧跟 `else` → 正常。
- **相邻拒绝**:`255U8` 等词法回落产生 `Int` 后跟 `Ident`——表达式解析结束后语句层遇到非 Newline/`}`/EOF/AssignOp → E1001"意外的记号"(天然覆盖相邻性;消息含记号与位置)。
- **`static var` 恢复**:`static` 后是 `var` → E3030"static var 不存在;用 static let 或 Global[T]",消费 `var` 后按 static let 继续解析(声明记 was_var)。
- **块**:`{ NEWLINE* { 项 NEWLINE+ } [尾表达式 NEWLINE*] }`;语句层 `let/var/return/for/while` 关键字分流,`target op= value` 按"表达式后跟 AssignOp"识别;其余为表达式语句。
- **match 臂**:换行分隔;`Pattern => Expr`;穷尽性检查属 P1-C,本阶段不查。
- **模式**:字面量/`_`/标识符/元组/`Path(...)`/`Path { f, g: pat }`;`Path` 为 1–n 段标识符。
- **类型**:`&` 前缀;基元 = 路径[类型实参] | `fn(`类型列表`)` [`->` 类型] | 元组 | `self`;后缀循环:`[]` 切片、`[Expr]` 定长、`?` 可选。
