# 计划:ctron fmt 双宿主移植(C 宿主 + 自举编译器)

日期:2026-09-21
状态:实施中
上游:R-P2d(`compiler-rust/src/fmt.rs` 参考实现 + `docs/fmt-spec.md` 唯一权威规范,2026-09-12 落地)

## 目标

`ctron fmt` 目前只存在于 Rust 宿主。本计划把同一规范(docs/fmt-spec.md R1–R8 + CLI 契约)
移植到另外两个宿主,并钉死三宿主输出逐字节一致:

1. **compiler-c(C 宿主)**:`ctronc fmt <file|pkg目录> [-w] [--check]`,完整 CLI 契约。
2. **compiler(自举 Ctron)**:fmt.ct + driver_fmt.ct → `bin/ctron-fmt`(stdout 核心),
   `-w/--check/pkg 目录`在 ctc 驱动层(shell)编排。
3. **parity 门禁**:Rust / C / 自举三宿主对同一语料的 fmt 输出逐字节一致。

## 载体层决策

### compiler-c:直接复用 ctron_lex(与 Rust 同构)

`ctron_lex` 返回带字节 span(line/col/start/end)的过滤流,与 `crate::lex` 同构 →
`src/fmt.c` 1:1 移植 fmt.rs(注释回收、括号配对、空格表、链断行、块多行性全部照搬)。
CLI 在 main.c 加 `fmt` 子命令,语义逐条对齐 compiler-rust/src/main.rs:386-457
(目录展开 src/*.ct 否则直下、文件名序;--check 列出待格式化 + 非零退出;-w 原位写回;
词法诊断 → stderr + rc=1)。

### compiler:scan4 无 span → 加 scan5(加法改造),fmt.ct 自含发射器

自举词法器 `scan4` 只出 token 串+行列,注释被吞、无字节 offset——而 fmt 的布局权威恰是
原始间隙。方案:**lex.ct 加 `scan5`**(原始流 + token span(List[I32])+ 注释 span,
注释不吞),`scan4` 变为 scan5+filter_nl 的薄 wrapper——现有调用面(driver_*/parse_pkg)
零变更,fmt 消费 scan5 原始流(NL 记号由发射器跳过;布局决策全部来自 span 间隙,
与 Rust 在过滤流上跳过 Newline 等价)。fmt.ct 本体只含发射器与纯查询助手,不自带第二词法器。

### 编排与旗标(自举侧)

发射样板 main 的旗标表(--format/--profile/--trusted/--dump-gui)是共享基建,**不动**;
native `ctron-fmt` 只做单文件 stdout 核心(`ctron-fmt run <file>`,诊断 rc=1),
`-w/--check/pkg 目录`由 ctc(ctc.ps1 同文)在 shell 层编排——与 Rust CLI 契约同语义同 rc。

### 语言子集约束(fmt.ct,写码前对照双宿主分歧清单)

- 无 struct:发射器状态收进单个大 fn 的局部变量;助手只做纯查询(空格表/自由换行数/
  操作数收尾/块多行性);注释消费用游标不用 remove;括号配对栈用 top 计数器不用 pop。
- prev_real 栈在 fmt.rs 中只有尾元素被读 → 单 `prev: Str` 标量即可。
- 数字 token 含 `~`(text~sfx)→ `num_text` 剥后缀即 span 原文,字面量零改写(R7)。
- 跨行参数表禁用(E1001)、单字母大写标识符禁用、fn(){} 字面量禁用(管道闭包才安全)。
- List[I32] 双宿主可用(trans_*.ct 在用)。
