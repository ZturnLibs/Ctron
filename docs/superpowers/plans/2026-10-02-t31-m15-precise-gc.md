## 已知安全性论证(写码前必读)

1. **喂词安全**:`ct_gc_mkword` 先做超块区间检查,非 GC 堆词自动无操作 → 宽注册不炸,漏注册才 UAF。注册谓词宁宽勿缺。
2. **kind 分派**:值结构体槽(`u:`/`R`/`E:` 前缀)必须 kind 1 域扫(词标读首 8 字节=漏字段→UAF);其余全 kind 0。施工时以 ct_ctype 尾段复核结构体值码全集。
3. **逃逸地址强制落内存**:槽地址进链后,任何不透明调用(GC 触发点=ctron_list_new/Box/into_gc/ct_ig_l)前 C 编译器必须将当前值写回内存槽(别名规则);`ct_gc_alloc` 入口加内存屏障双保险。
4. **递归安全**:槽节点=自动存储期(每激活一份);static 节点在递归下会产生 S.nx=S 自环(已否决,勿用)。
5. **尾声统一**:`__attribute__((cleanup))` 覆盖全部 return 路径;longjmp 跳过 cleanup → panic 落点(ct_shim_tramp setjmp 返回非零处)显式复位 `ct_fp=0`。
6. **线程**:`ct_fp` 必须 `__thread`(ct_pmap 8 线程并发推拉全局链=竞态;GC 收集仅主线程,任务线程分配已退避 bump=arena 根扫覆盖)。
7. **死槽读安全**:语句表达式临时/死作用域槽节点残链,读的是当前栈_extent 内旧值(可读),词经 mkword 区间检查,仅过标记(安全方向)。

### Task 1: S1a 标记器硬化——超块尺寸类+内部指针块起点归约+新超块清零

**Files:**
- Modify: `compiler/src/driver_emit.ct`(GC 运行时字符串段:131-147 行区)

**Interfaces:**
- Produces: `ct_sb` 增 `size_t bsz`(块尺寸类,块步距=16+bsz);`ct_gc_mkword` 内部指针先归约块起点再读头。后续 Task 的精确走链直接消费 mkword 语义。

背景:T31 路线② SIGSEGV 真因=内部指针(载荷词)被当块头读,hdr[1] 载荷巧合值 ∈{1} → hdr[0] 载荷当尺寸 → mkrange 野扫越界解引用。修法=分配定尺寸类,O(1) 归约块起点;头有效性双门(h[1]∈{0,1,2} 且 h[0]≤sb 容量)。

- [x] **Step 1: 改 ct_sb 定义与分配/回收路径**

ct_sb 增 `bsz` 字段;`ct_gc_alloc` 新超块分支:首次分配定级(bsz=≥32 的 2 的幂,容纳 sizeof(ctron_list)=24→32),块步距固定;free-list 复用按「bsz≥sz」匹配;新超块内存**清零**(calloc 或 malloc+memset——未用块头读 0=mkword 天然无操作,消灭垃圾头)。头布局不变(h[0]=用户 sz,h[1]=标记态,h[2]=fl 链)。

运行时 C 语义(发射串内容,按现有 `\{`/`}` 纪律落 println):

```c
typedef struct ct_sb { struct ct_sb* nx; char* cur; char* end; void* fl; size_t cap; size_t live; size_t bsz; } ct_sb;
// alloc 新超块分支:cap 取整到尺寸类倍数;memset 清零;h[0]=sz;步距 = 16+bsz
// free-list 匹配条件:h[0] >= sz 且该 sb 单类(h[0]<=s->bsz 恒真,免判)
```

- [x] **Step 2: mkword 归约+双门**

```c
static void ct_gc_mkword(void* w) {
  ct_sb* s = 0;
  for (ct_sb* q = ct_gc_sbs; q; q = q->nx) {
    char* b = (char*)(q + 1);
    if ((char*)w >= b && (char*)w < q->end) { s = q; break; }
  }
  if (!s) return;
  size_t st = 16 + s->bsz;
  size_t off = (size_t)((char*)w - (char*)(s + 1));
  char* p = (char*)(s + 1) + (off / st) * st;          /* 内部指针 → 块起点 */
  size_t* hdr = (size_t*)p;
  if (hdr[1] != 1) return;                              /* 0=空闲/2=已标/垃圾=拒 */
  if (hdr[0] == 0 || hdr[0] > s->bsz) return;           /* 头有效性双门 */
  hdr[1] = 2; ct_gc_livesz += hdr[0];
  ct_gc_push(p + 16, hdr[0]);                           /* S1b 前暂仍调 mkrange */
  /* ctron_list magic 特判保持:items 数组域入 worklist */
}
```
