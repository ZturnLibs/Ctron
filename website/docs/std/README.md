# Std Reference

Signature tables and per-item descriptions are generated by [tools/std_doc.py](https://github.com/ZturnLibs/Ctron/blob/main/tools/std_doc.py) from `lib/std/*.ct` source doc comments (ctron-doc iface projection). Module description sections between the `hand:desc` markers are hand-written.

> Agent channel: `compiler/ctc.sh doc lib/std/<mod>.ct --format=json` (pub symbol table with doc comments, deterministic).

> Chinese translations of the Std Reference are pending; descriptions follow source comments (mostly Chinese) for now.
