# gui_zitie —— 中文字帖(中文显示验证专例)

竖排列版式的字帖应用:72px 大号汉字逐字断言,是 M3 合流后 FreeType 文本管线
(实测测量 + 字符串纹理缓存)的观感与正确性双重验证样例。

- 内容源:`zitie.txt` 存在则读入(换掉它 = 换字帖)= 千字文全文 1000 字(50 整页;
  缺省兜底为首段 32 字)。6 个重复字(发云昆巨戚洁)系简繁合并产物,原文本各自不重
- 每页 20 字 = 5 列 × 4 字(列内纵排);「换页」翻页、Esc 回首页
- 断言:逐字 TEXT 命令字节、`gui_ft_measure(72)` 大字号实测、命令数精确(24)、
  翻页链(第 2/3 页)+ Esc 回首页

## 运行

```sh
sh run.sh          # 构建 + headless 全链路断言(全自动)
sh run.sh --run    # 追加真实窗口(点「换页」翻页)
```

## 文件导览

- `app.ctml` —— 视图:头部行(换页按钮 + 标题/页码槽)+ hbox 内 5 个 each 列
  (each 的垂直容器即"列",古籍竖排)
- `src/main.ct` —— 内容切分(UTF-8 逐字)/ 列填充 / 翻页动作 / bind 通道
- `zitie.txt` —— 字帖内容(可换;去空白后任意汉字序列)

## 当前能力边界(如实登记)

- 深底白字笺样式:域包「容器嵌套 each」(vbox/hbox 内含 each)与「each 挂 class」
  两路径段错误(已登记归域包泳道),宣纸格底暂不可达;格线以列间距示意
- 无注音/笔画/描红;字号为静态样式值(bind 驱动字号待 style 插值面)
- 列内行距 = 文本行高 1.25 倍字号(不可调;each 挂 class 修复后可经容器 gap 开)
