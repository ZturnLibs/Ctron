# gui_calc —— 仿 macOS 计算器(L1 域包形态)

参照 macOS 系统自带基础计算器:深色面板 + 右对齐大字号显示 + 4×5 按键面。
**用户树零 `#[trusted]`、零解析器、零事件循环**——平台全部在 `std/gui` 域包
(`use std.gui`,SL-4 切包,2026-09-20;历史自包含形态见 git)。

## 运行

```sh
sh run.sh          # 构建 + headless 全自动断言(四则/链式/除零/溢出/小数/键盘)
sh run.sh --run    # 真实窗口:鼠标点按键;键盘 0-9 . + - * / = Enter ESC %
```

## 亮点

- **十进制字符串算术**(业务,~600 行):无浮点——0.1+0.2=0.3 精确;1÷3 =
  0.333333333333(12 位四舍五入);除零/溢出 → Error;
- **经典状态机**:输入中/待运算链(2+3+ 即时折叠)/等号;
- **深度 2 嵌套布局**:根 vbox → 显示 + 5×hbox 行 → 19 按钮;多类样式(`num zero` 双宽);
- **双输入**:鼠标(布局回填几何命中)+ 键盘(`key_name` 语义名 → 业务映射)。

## 文件导览

- `app.ctml` —— 视图结构 + 样式
- `src/main.ct`(~990 行)—— 领域(算术 + 状态机)+ 双口径装配:
  headless 走域包 `test()`(场景脚本 ~90 行,原 180 行脚手架);窗口走 `run_kb_d`
- 平台单一真源:`std/gui.ct` + `std/gui/c_src/ctron_gui.c`

## 边界(如实)

- 运算简化:等号不重复求值;± 后输入追加;超 ±9999999999 → Error(非科学计数)
- 字形 ÷ × ± 走默认字体 Latin-1;减号 ASCII(M3 后全 Unicode)
- 解释口径 read_file 有 T/Some 回归(登记收敛设计 §7-⑨),当前以原生口径为准
