# Ctron 编译器 C 版(C1 里程碑:词法器)

> **分支**:`discuss-c-implementation`。**决策记录**:Ctron 存在两套独立、各自完整的编译器实现——Rust 版(`compiler/`)与 C 版(`compiler_c/`),互不依赖;两者共享**语言设计**(`docs/superpowers/specs/…ctron-language-design.md`)、**规范**(`docs/spec/` v0.5)与**一致性语料**(仓库根 `tests/`,61 文件)。最终自举目标不变:以 C 版为种子编译器,后续用 Ctron 自身实现 Ctron。

## C1 里程碑(本文件)目标

在 `compiler_c/` 内独立实现规范 §1 的词法器:

- 记号模型(§1.3 关键字/§1.4 字面量/§1.5 运算符)与换行显著性过滤(§1.6);
- 诊断码 `E1001`(词法阶段全部语法错误),消息中文、含位置;
- 错误恢复为**循环**(吞错误记号后主循环续取),非递归——100k 连续 `;` 不栈溢出;
- 关键行为锚点(与 Rust 版同源于规范 §1,验收口径一致):
  ① 进制前缀/后缀**仅小写**(`0XFF`→`Int("0")+Ident("XFF")`;`255U8`→回落);
  ② `..=` 最长匹配;③ `.` 后整数点号判浮点需后继数字(`21.double()` 非浮点);
  ④ 字符串转义含 `\u{HEX}`(溢出/代理区 → E1001);⑤ 插值单行、不跨串配对、字面 `{` 须 `\{`(裸 `{` 无配对 → E1001);
  ⑥ 保留运算符字 `or` 在成员位置(前记号是 `.`)按 `Ident` 产出;⑦ `_` 独立记号。

## 目录与构建

```
compiler_c/
  Makefile              # make / make test / make clean
  src/arena.{h,c}       # 块链 bump 分配器:编译器对象整体一次释放,无逐对象 free

  src/main.c            # CLI: ctronc <version|lex|parse>
  tests/test_lex.c      # 单元测试(58 断言,锚定 §1 行为)
  tests/suite_lex.c     # 集成:遍历 ../tests 61 文件,断言零词法诊断
```

构建环境:仅 libc,C11(`cc`);零外部依赖。验收命令 `make test`。

## C 版架构决策(贯穿后续里程碑)

- **内存**:编译器进程短命 → 单 arena 块链分配,记号载荷/字符串全在其中,结束整体释放;动态数组(tokens/diags/bytes)堆增长、内含 arena 指针不随 realloc 失效(载荷永不动)。
- **记号**:判别式结构体(kind + 后缀/文本/部件三选一的载荷),与规范一一对应。
- **确定性**:产出顺序只依赖源码;诊断按出现序输出(与语料验收一致)。
- **字符串部件**:转义在词法期解码为 `Text`;插值原文以 `Interp` 原始切片保留,解析期再子解析。

## 验收(DoD)

1. `make test` 全绿:58 断言 + 61 文件集成(零诊断、记号数 ≥ 2);
2. `ctronc lex` 行为正确:诊断格式 `文件:行:列 码: 消息`,无诊断退出码 0;
3. ASan/UBSan 下单元与集成全绿;
4. 100k 连续 `;` 不栈溢出(循环恢复)。
